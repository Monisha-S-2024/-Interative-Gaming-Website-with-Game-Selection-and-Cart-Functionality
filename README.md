🎮 Gaming Zone – Web-Based Gaming Website

📌 Project Overview

Gaming Zone is a simple and interactive web-based gaming website developed using HTML and CSS with basic JavaScript functionality.

The website provides a platform to explore different indoor and puzzle games through an attractive dark-themed interface. Users can browse available games and interact with the Add to Cart buttons.

🎯 Project Objectives

Design an attractive gaming website.

Display different categories of indoor and puzzle games.

Create a user-friendly navigation section.

Implement basic interactive functionality.

Practice frontend web development concepts.

🎲 Available Games

The website showcases six games:

Ludo – A classic family game for all ages.

Cards – A game of strategy and entertainment.

Carom – An indoor game of skill and precision.

Snakes and Ladders – A classic game of luck and strategy.

Word Search – A puzzle game to sharpen the mind.

Sudoku – A number-based puzzle challenge.

✨ Features

Dark-themed website design.

Navigation bar with Home, Games, News and Contact links.

Hero section with a gaming introduction.

Grid-based game display.

Individual game images and descriptions.

Add to Cart buttons with JavaScript alert interactions.

Footer with copyright information.
